# Проект: автопостинг в Max Messenger

## Команда «Сгенерировать пост»

Когда пользователь просит сгенерировать пост о здоровье, строго следуй алгоритму ниже.

---

## Шаг 1 — Поиск свежей новости

Выполни WebSearch по следующим запросам:
- `медицина на дому здоровье упражнения домашние средства лечения новости 2026`
- `здоровье на дому советы 2026 апрель`

Критерии отбора:
- Опубликована за последние 24–48 часов
- Тема: домашние средства лечения, упражнения для здоровья дома, здоровое питание, народная медицина
- Практична и применима в жизни (не законодательство/бюрократия)
- Понятна широкой аудитории без медобразования

---

## Шаг 2 — Проверка в Notion (не брали ли эту статью раньше)

Запиши файл `article-check.json` в корне проекта:

```json
{ "url": "<URL найденной статьи>", "description": "<1-2 предложения о сути статьи>" }
```

Затем запусти через Bash:

```bash
npx playwright test tests/notion-check.spec.ts
```

Прочитай `article-check-result.json` и проверь два условия:
1. Если `urlMatch: true` — этот URL уже использовался, найди другую статью и повтори проверку.
2. Если `urlMatch: false` — прочитай список `recentDescriptions` и сравни семантически с описанием текущей статьи. Если по смыслу похожая есть — найди другую статью и повтори проверку.

---

## Шаг 3 — Написание поста для Max Messenger

Используй шаблон:

```
[ЭМОДЗИ] [ЦЕПЛЯЮЩИЙ ЗАГОЛОВОК — до 10 слов]

[Абзац 1 — суть новости, 2–3 коротких предложения]

[Абзац 2 — практическая польза / что делать, 2–3 предложения]

[Абзац 3 — конкретный совет или лайфхак, 2–3 предложения]

[ВОВЛЕКАЮЩИЙ ВОПРОС к аудитории?]
👍 — [ответ «да»]
❤️ — [ответ «нет» или альтернатива]
```

Правила стиля:
- Заголовок: с эмодзи, интригующий, до 10 слов
- Абзацы: 2–3 предложения, короткие и чёткие
- Тон: разговорный, дружелюбный, без канцелярита
- Максимально человеческий стиль, без признаков ИИ-генерации
- Вопрос в конце: простой, бинарный, с 👍 и ❤️

---

## Шаг 4 — Сохранение в Notion

Убедись, что в `post-content.json` есть поля `articleTitle`, `articleUrl`, `articleDescription` (добавь их при сохранении в шаге 6). Затем запусти через Bash:

```bash
npx playwright test tests/notion-save.spec.ts
```

Скрипт автоматически запишет запись в базу `used_articles` с текущей датой.

---

## Шаг 5 — Генерация промпта для картинки (kie.ai)

Напиши промпт на **английском языке** для генерации реалистичной фотографии к посту:
- Стиль: реалистичная фотография, как с фотоаппарата
- Если на фото есть человек — расположить так, чтобы лицо не было видно
- Избегать текста на изображении
- Соотношение сторон 4:3 (задаётся отдельно в API, в промпт не включать)
- Длина промпта: средняя, достаточная для генерации, без излишеств

---

## Шаг 6 — Сохранение контента в файл

Сохрани результат в файл `post-content.json` в корне проекта:

```json
{
  "postText": "полный текст поста",
  "imagePrompt": "английский промпт для kie.ai",
  "articleTitle": "заголовок поста (для Notion)",
  "articleUrl": "https://url-статьи",
  "articleDescription": "1-2 предложения о сути статьи (для Notion)"
}
```

---

## Шаг 7 — Автоматическая публикация в Max Messenger

Сразу после сохранения `post-content.json` — без каких-либо пауз и вопросов — запусти тест через Bash:

```bash
npx playwright test tests/send-post.spec.ts
```

Тест автоматически:
1. Читает `post-content.json`
2. Генерирует картинку через kie.ai (~1–3 мин)
3. Отправляет пост с картинкой в канал Max Messenger

Дожидайся завершения теста и сообщи пользователю результат.

---

## Шаг 8 — Вывод результата

Выведи пользователю:
1. Текст поста
2. Промпт для картинки
3. Статус публикации (успешно / ошибка)
